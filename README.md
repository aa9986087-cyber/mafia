# مافيا

لعبة مافيا جماعية أونلاين بالعربي، مصممة للجوال أولًا. الأدوار: مافيا وطبيب ومحقق ومواطنون. ليل ونهار ونقاش وتصويت، من جوالاتكم وأنتم جالسين مع بعض أو كل واحد في بيته.

**العب:** https://aa9986087-cyber.github.io/mafia/

## كيف تشتغل

- **الواجهة** في هذا المستودع: صفحات ثابتة على GitHub Pages (`index.html` و`css/` و`js/`)، بدون أي أداة بناء.
- **الخادم** في مجلد `server/` بهذا المستودع: Cloudflare Workers مستقل باسم `mafia-server`، لا يشارك أي لعبة ثانية في شيء. `server/room.js` فيه منطق اللعبة كامل، وكل غرفة Durable Object مستقل (`MafiaGame` في `server/worker.js`). العنوان `wss://mafia-server.<حسابك>.workers.dev/ws/<الرمز>`، ولا يقبل إلا صفحات هذا الموقع. Cloudflare ينشره تلقائيًا من مجلد `server` مع كل رفع على main.
- الخادم هو الحكم: يوزّع الأدوار ويحسب الليل والتصويت والفوز. كل لاعب يوصله دوره هو فقط، والمافيا يعرفون بعض، وتنكشف كل الأدوار في النهاية.

| الملف | ماذا فيه |
|---|---|
| `js/app.js` | الشاشات كلها: الرئيسية، اللوبي، كشف الدور بالضغط المطوّل، الليل، الصباح، النقاش، التصويت، النتيجة، النهاية |
| `js/net.js` | الاتصال اللحظي وإعادة الاتصال وساعة الخادم (من نظام الدخيل) |
| `js/sound.js` | مؤثرات صوتية مولدة بالمتصفح، كتم الصوت، الاهتزاز |
| `css/style.css` | الهوية: نوار داكن، قرمزي، ذهبي مطفي، خط Cairo وTajawal |

## القواعد كما في الخادم

- ٤ إلى ١٦ لاعبًا. المافيا ثلث الطاولة على الأكثر.
- الليل: المافيا يختارون ضحية (إذا كانوا أكثر من واحد يظهر لهم شات سري ولازم يتفقون، وإلا يُختار الأكثر اختيارًا)، الطبيب يحمي شخصًا (لا يكرر نفس الشخص ليلتين، وحماية نفسه حسب إعداد الغرفة)، المحقق يفحص شخصًا ويعرف النتيجة فورًا. المواطنون يختارون "من يشكّون فيه" بلا أثر، حتى تكون كل الشاشات متشابهة.
- الصباح: إعلان من طلع، أو أن الطبيب أنقذ الضحية، أو ليلة هادئة.
- النهار: نقاش بمؤقت، وإذا ضغط أغلب الأحياء «جاهز للتصويت» يبدأ التصويت مباشرة. التعادل لا يُطلع أحدًا.
- الفوز: المواطنون إذا طلعت كل المافيا، والمافيا إذا صار عددهم مثل الباقين.
- الانقطاع: في اللعبة دقيقة كاملة للرجوع لنفس المقعد، بعدها يُحسب اللاعب خارجًا ولا تنتظره الجولة. المضيف ينتقل تلقائيًا.

## التجربة محليًا

```bash
cd server && npm install && npm test   # اختبارات منطق اللعبة
npm run dev                            # خادم الغرف على ws://localhost:8787
# وفي جذر المستودع: الصفحات
python3 -m http.server 8080
# ثم افتح: http://localhost:8080/?server=ws://localhost:8787
```

صُنعت في الرافعية بيد Vamos.
